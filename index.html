Rosto Secreto

Adivinhação para 2 jogadores

Quem está no cartão secreto do seu amigo?

Cada um recebe um rosto entre 24. Façam perguntas de sim ou não, virem os rostos descartados e acertem primeiro.

Mande o mesmo código para seu amigo. O código define o tabuleiro, então os dois veem os mesmos 24 rostos.

Como jogar

  1. Os dois entram com o mesmo código. Cada aparelho sorteia um rosto secreto.
  2. Na sua vez, faça uma pergunta de sim ou não, como “Usa óculos?”.
  3. Toque nos rostos que não batem com a resposta para virá-los.
  4. Quando tiver certeza, use “Dar palpite”. Errou o palpite, perdeu a rodada.
